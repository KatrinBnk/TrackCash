# TrackCash

Приложение "TrackCash" — это клиент-серверное веб-приложение для учета личных расходов. 

Приложение разрабатывается в рамах курсовой работу по курсу "Технологии Веб-программирования" (вариант работы 22)

## Описание
Приложение позволяет:
- **Администраторам**: управлять пользователями, отделами.
- **Менеджерам**: планировать ресурсы, управлять категориями расходов и просматривать статистику отдела.
- **Сотрудникам**: вести записи о расходах/доходах и просматривать личную статистику.

## Технологии
- **Клиент**: HTML, CSS, JavaScript, jQuery, Mocha, Handlebars(1)
- **Сервер**: Node.js, Express, MySQL, JSON, AJAX, NPM
